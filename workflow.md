# Workflow

1. Start application.
2. Enter Team 1 and Team 2 names.
3. Enter 11 players for each team.
4. Enter number of overs.
5. Start first innings.
6. Select bowler.
7. Enter each ball result.
8. Update score/player/bowler statistics.
9. Continue until innings ends.
10. Display first scorecard.
11. Calculate target.
12. Start second innings.
13. Repeat ball-by-ball process.
14. Display second scorecard.
15. Calculate and display result.
16. End application.
